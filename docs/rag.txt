Retrieval-Augmented Generation (RAG) combines a retriever with an LLM. The retriever finds relevant documents for a query, and those documents are added to the prompt so the LLM can answer using them.
RAG reduces hallucinations because answers are grounded in retrieved sources. It also allows knowledge updates without retraining the model.
A typical RAG pipeline has these steps: load documents, split them into chunks, embed or index the chunks, retrieve the top-k chunks for a question, build a prompt, and generate the answer.
